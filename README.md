# Python Practice Projects 🐍

## About This Repository

This repository contains five Python programming projects created to improve coding skills and logical thinking. These programs cover strings, numbers, lists, loops, and basic mathematical operations.

## Projects Included

### 1. Reverse a String
Reverses a string entered by the user using Python string slicing.

**Example:**
- Input: `python`
- Output: `nohtyp`

### 2. Sum of Digits
Calculates the sum of all digits in a given number.

**Example:**
- Input: `1234`
- Output: `10`

### 3. Prime Numbers in a List
Finds and displays all prime numbers from a list of numbers entered by the user.

**Example:**
- Input: `2 4 5 7 9 11 15`
- Output: `2 5 7 11`

### 4. Common Elements in Two Lists
Finds the common elements between two lists without displaying duplicates.

**Example:**
- First list: `10 20 30 40`
- Second list: `20 40 50 60`
- Output: `[20, 40]`

### 5. Simple Interest Calculator
Calculates simple interest using the principal amount, interest rate, and time.

**Formula:**

Simple Interest = (Principal × Rate × Time) / 100

**Example:**
- Principal: `10000`
- Rate: `5`
- Time: `2`
- Output: `1000.0`
